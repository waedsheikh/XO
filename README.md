# ❌⭕ Tic-Tac-Toe Game (XO)

A interactive Tic-Tac-Toe (XO) game built using JavaScript, HTML5, and CSS3.

---

### ✨ Features
- 🎮 Interactive player vs player gameplay.
- 🎨 Clean design and smooth animations.
- 📱 Fully responsive for mobile and desktop screens.

---

### 🛠️ Tech Stack
- HTML5 - Game interface
- CSS3 - Styling & layout
- JavaScript - Game logic & state management
